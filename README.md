  # Academy Management System 🎓  

## Overview  
This project is an **Academy Management System** designed to manage courses, teachers, and students. With this system, users can:  

- **Register** teachers and students.  
- **Create and manage** courses and classes.  
- **Manage students** in each class.  
- **Track student payments** and **teacher earnings**.  
- **Automatically reset student payments** at the end of each billing cycle for monthly renewals.  
- **Filter students** based on their class or teacher.  

## Features 🚀  
✔️ Teacher and student registration  
✔️ Course and class management  
✔️ Display list of teachers and students  
✔️ Manage student payments and teacher earnings  
✔️ Filter students based on class or teacher  

## Technologies Used 🛠️  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Frontend:** HTML, CSS, jQuery

# **سیستم مدیریت آکادمی 🎓**  

## **معرفی**  
این پروژه یک **سیستم مدیریت آکادمی** است که برای مدیریت دوره‌ها، اساتید و دانشجویان طراحی شده است. با استفاده از این سیستم، کاربران می‌توانند:  

- **ثبت‌نام اساتید و دانشجویان** را انجام دهند.  
- **ایجاد و مدیریت دوره‌ها و کلاس‌ها** را انجام دهند.  
- **مدیریت دانشجویان** در هر کلاس را انجام دهند.  
- **پرداختی‌های دانشجویان** و **دریافتی‌های اساتید** را ردیابی کنند.  
- **پرداخت دانشجویان را به‌طور خودکار در پایان هر دوره پرداختی صفر کنند** تا برای ماه بعد پرداخت مجدد انجام شود.  
- **دانشجویان را بر اساس کلاس یا استاد فیلتر کنند.**  

## **ویژگی‌ها 🚀**  
✔️ ثبت‌نام اساتید و دانشجویان  
✔️ مدیریت دوره‌ها و کلاس‌ها  
✔️ نمایش لیست اساتید و دانشجویان  
✔️ مدیریت پرداختی دانشجویان و درآمد اساتید  
✔️ فیلتر دانشجویان بر اساس کلاس یا استاد
