  # Academy Management System 🎓  

## Overview  
This project is an **Academy Management System** designed to manage courses, teachers, and students. With this system, users can:  

- **Register** teachers and students.  
- **Create and manage** courses and classes.  
- **Manage students** in each class.  
- **Track student payments** and **teacher earnings**.  
- **Automatically reset student payments** at the end of each billing cycle for monthly renewals.  
- **Filter students** based on their class or teacher.  

## Features 🚀  
✔️ Teacher and student registration  
✔️ Course and class management  
✔️ Display list of teachers and students  
✔️ Manage student payments and teacher earnings  
✔️ Filter students based on class or teacher  

## Technologies Used 🛠️  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Frontend:** HTML, CSS, jQuery
